# Changelog

Releases carry `SIGSEEK.COM` and `SIGSEEK.DAT`; copy both onto a disk, side by side.

## 1.51.2 (2026-11-13)

- The title screen's name and "press any key" are centred.

## 1.51.1 (2026-11-05, first release)

The game as it stands: a live spectrogram you tune by hand (or let AutoTune have a go at), packets
with noisy bits to flip clean, a relay-routing puzzle for the callers' letters, eight recurring
callers, postcards, a stamp book, an Archive and one last lantern, a shop and a shelf for the
station, PIXEL the cat, weather and static storms, a night that ends at dawn, special nights by the
real date, echoes, a help screen, printing on the FX-80, and a save file.

- Fix: caught signals leave the band; a lock on another signal starts afresh; fairer dice.

Earlier versions (1.29 to 1.51) are in the git history; each feature commit names its version.
